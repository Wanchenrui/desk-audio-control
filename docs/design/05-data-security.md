# 数据、隐私、安全与现有模块映射

## 数据与隐私

- v1.1 将配置和决策日志放在 `%LocalAppData%\DeskAudioControl`。首次运行从旧注册表迁入普通设置、用途偏好和 USB 身份冲突记录。系统登录启动项与 DPAPI 凭据保留原位置。
- 日志环形保留 30 天，支持导出、导入和一键清除。
- 永不保存音频内容，只保存电平统计和频谱形状。会议态只读系统占用状态。
- 更新检查之后增加下载包的哈希与签名校验。令牌继续用 DPAPI 保存。
- 失败安全：任何异常都退回手动控制，不干扰 Windows 原有行为。
- 企业场景支持组策略锁定自动化。

## 与现有模块的映射

| 现有模块 | 演进方向 |
| --- | --- |
| `AudioCore` | 变成平台适配层，缓存 COM 对象，拆分路由、音量、电平 |
| `AudioDiscovery` | 变成设备图和数字孪生，保留已有测试覆盖的分组逻辑 |
| `SmartPolicy` | 变成策略引擎的硬约束前置过滤，抽象成接口 |
| `EndpointEvents` | 已接入事件总线，类型和触发时间用于去抖和决策记录 |
| `AudioTuning` | 需要替换。它靠自动化操作系统声音面板来点开增强页，依赖界面文字和窗口结构，系统语言或版本一变就会失效 |
| `UpdateCheck` | 保留，补完整性校验 |
| `Theme`、`Ui*`、`AudioPanel*` | 保留，OSD 和命令面板直接复用 |

## 已知技术债

- **未公开接口。** `IPolicyConfig` 和每应用路由都是 Windows 的内部接口，需要版本探测和降级路径。
- **DPI。** 目前只声明了系统级感知，窗口拖到缩放比例不同的显示器上会被系统拉伸。逐显示器感知需要让字体随 DPI 重建。
