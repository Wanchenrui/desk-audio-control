# 交互层与开放接口

## 交互层

- **灵动岛式 OSD。** 发生切换时，屏幕边缘弹出 1.2 秒的胶囊：设备图标、名称、响度条、撤销。全屏游戏时降级为托盘气泡。
- **命令面板**（如 Ctrl+Alt+Space）。模糊搜索设备、场景和动作。支持自然语言，例如把音乐放到音箱，在本地解析成结构化动作。
- **场景卡片。** 会议、影音、专注、夜间各一键，每个场景是一份可编辑的设备、音量、处理链快照。
- **活动时间线。** 新增页面，像 git log 一样列出插拔、切换、纠正、异常，每条都带为什么和撤销。
- **信任仪表。** 显示本周自动切换 N 次，被纠正 M 次，让用户看到智能在变好。
- **硬件联动。** 蓝牙佩戴检测、USB 静音键和指示灯同步、Stream Deck 或宏键盘映射。
- **无障碍。** 键盘全覆盖、屏幕阅读器名称、高对比主题，可选提示音反馈。

新界面的控件库（`Theme.cs`、`Ui*.cs`）是这些功能的基础，OSD 和命令面板直接复用。

## 开放接口

- **本地 API。** 仅限当前用户的命名管道，JSON-RPC：`devices.list`、`route.set`、`scene.activate`、`explain`、`undo`。同时提供 CLI（`deskaudio scene meeting`）和 `deskaudio://` 链接。
- **MCP 服务器。** 让 AI 助手在授权范围内读取音频状态、触发场景。权限分三级：只读、场景、路由。每次调用写入决策日志，改默认输入这类高风险动作必须由用户确认。

## LLM 的边界

LLM 只负责把意图翻译成结构化动作，以及润色解释。决策和执行仍由策略引擎校验。没有网络时，规则解析兜底。网络和 LLM 功能默认关闭。
