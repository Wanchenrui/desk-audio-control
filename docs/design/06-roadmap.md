# 路线图、验收与风险

## 路线图

| 阶段 | 内容 |
| --- | --- |
| P1 地基（v1.1 已实现） | 后台扫描与去抖、事件总线、决策日志与撤销、OSD、配置存储 |
| P2 智能切换（v1.3 已实现） | 规则版场景识别、评分与迟滞、四级自治、会议与蓝牙规避、活动时间线 |
| P3 调优 | 等响切换、柔着陆、麦克风医生、EQ 推荐 |
| P4 生态 | 管道 API 与 CLI、命令面板、宏键盘、MCP |
| P5 深水区 | 虚拟设备与处理链（需驱动签名）、降噪、房间校正、真交叉淡化、多机协同 |

## 验收指标

- 从事件到默认设备切换完成，中位数低于 500 毫秒。
- 稳定期自动动作被撤销的比例低于 5%。
- 打断通话的误切换为 0。
- 插拔抖动 100% 被合并。
- 空闲 CPU 低于 0.5%，内存低于 80 MB。
- 测试沿用现有的模拟数据思路，新增决策回放：录下事件序列，重放后断言决策结果，让智能行为也能做离线回归。

v1.1 与 v1.3 的端点回放和本机空闲基线见 [维护记录](../MAINTENANCE.md)。真实 USB、蓝牙设备的延迟分布及长期撤销率需要在实际使用中统计。

## 主要风险

- 驱动签名的成本。
- 杀毒和反作弊软件对注入类手段敏感，所以只用官方接口和处理链，不做钩子。
- 未公开接口随系统更新失效。
- 学习误判，用低自治默认加护栏兜住。

## 远景

- **跟人走的声音。** 用蓝牙或超宽带估计你靠近哪台设备，声音自动跟过去。
- **音频时间机。** 持续保留最近十分钟的状态快照，出错时一键回到之前。
- **设备健康周报。** 例如这个 USB 耳机本周掉线 3 次，建议换口。
- **多机协同。** USB 外设被切换器切到另一台电脑时，这台电脑主动释放，对方接手，场景一起交接。
- **夜间自适应。** 到了睡觉时段，自动压缩动态范围并降低输出上限。
- **个人声学档案。** 把响度偏好和均衡习惯随身携带，换电脑、换耳机都能还原。
