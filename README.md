# 桌面音频 · DeskAudio

Windows 托盘音频面板。接入或拔出 USB、蓝牙设备时，面板会刷新列表，并把同一外设的播放和录音端口归为一项。遇到同时提供输入和输出的耳机、话筒或声卡，可以指定实际用途，供下次接入时沿用。

## 下载与更新

1. 用有权访问这个私有仓库的账号登录 GitHub，在 [最新正式版](https://github.com/Wanchenrui/desk-audio-control/releases/latest) 的 **Assets** 下下载 **DeskAudio.exe**。
2. 将 EXE 放在准备长期使用的文件夹里，双击即可运行。程序适用于 64 位 Windows 和 .NET Framework 4.8 或更高版本。换电脑时会重新识别该机的设备。
3. 从 v1.2.0 起，打开 **更新 → 立即检查**。发现新版本时，点击 **更新至 v… 并重启**。程序会下载附件、验证大小、SHA-256 和程序集版本，然后从原路径重启。下载或校验失败时可以直接重试，新版启动失败时更新组件会尝试恢复旧版。每天一次的后台检查只负责提醒，安装由你发起。

**从 v1.0.0 或 v1.1.0 首次升级**：这两个已发布版本的更新按钮会打开 GitHub。下载 v1.2.0 或更高版本的 `DeskAudio.exe`，从托盘退出旧版后替换原位置的文件并运行。之后即可在应用内完成升级。使用当前 Windows 账户可写的安装目录，即可原位替换并保留登录启动路径。

浏览器登录用于手动下载。要让程序检查这个私有仓库，在 **更新** 页勾选 **允许使用本机 GitHub 登录检查更新**，即可使用已登录的 Git for Windows 或 GitHub CLI。如果新电脑只有这个 EXE，在 **设置更新凭据** 保存一枚细粒度令牌即可。创建时将资源所有者设为 `Wanchenrui`，只选 `desk-audio-control` 仓库，仓库权限选择 **Contents → Read-only**。Windows 使用当前用户的账户加密保存该令牌，可从同一入口移除。[GitHub 令牌说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)

| 操作 | 入口 |
| --- | --- |
| 轮换当前可用的日常播放设备 | `Ctrl + Alt + F8` |
| 撤销最近一次自动切换，恢复原来的三个默认输出角色 | `Ctrl + Alt + F9`、屏幕提示或托盘菜单 |
| 将当前默认话筒静音或取消静音 | `Ctrl + Alt + F7` |
| 调音量、左右平衡，或打开驱动提供的声音增强 | 在面板中选中设备 |
| 查看板载、显示器或虚拟线路 | 打开“显示其他接口”开关 |

关闭面板后，快捷键继续在托盘中工作。左键单击托盘图标会弹出快捷面板，可以切换输出设备、调音量和静音，也可以从那里打开完整面板；右键菜单提供同样的输出切换，以及撤销和活动时间线。要退出程序，右键单击托盘图标并选择“退出”。

## v1.6.0 正式版

v1.6.0 改进了设备在线判断、通话期间的切换保护和耳机淡入。麦克风诊断可报告持续单音及回声延迟，耳机 EQ 可按端口应用到 Equalizer APO。可调参数和测量范围见[算法说明](docs/design/08-algorithm-implementation.md)。

## P2 智能切换

在 **切换与设置** 控制智能切换。全新安装默认开启，从旧版升级会保留原来的开关状态。首次扫描记录基线。设备接入、断开或场景稳定改变时，程序会给当前可用输出评分。评分考虑设备用途、最近接入、声道、场景适配、使用偏好和活跃会话数。**保守 → 积极** 滑杆调节新候选必须领先当前输出多少分。分数接近或多个候选并列时保留当前选择。同一设备和场景累计至少 8 次已稳定的本地执行后，模型会根据保留和纠正次数调整相对胜算。回放页显示调整依据和从通知到角色读回的分段耗时。

设备页显示端口的在线证据。只有 Windows 活动端点时，最多给出点击确认建议。驱动报告插头拔出或蓝牙链路断开时排除该端口。有冲突证据或多次快速纠正时只提醒。共享端口有未知来源播放时需要点击确认。

前台应用类别、音频会话、Windows 摄像头占用记录、时段和空闲时间用于识别会议、音乐、影音、游戏、专注、录制、夜间和离开，普通使用显示为日常。连续插拔通知合并 400 毫秒。场景变化需持续至少 5 秒，上一场景至少驻留 15 秒。会议、录制、离开和占用不明会立即阻止自动动作。切换或手动纠正后的 30 秒内保留用户选择。

| 自治级别 | 实际行为 |
| --- | --- |
| 只提醒，不切换 | 显示建议，由用户自行选择设备 |
| 点一下再切换 | 在屏幕提示、设置或托盘接受建议，60 秒内有效，执行前重新检查设备、评分和占用 |
| 自动切换，可撤销 | 自动切换，显示可撤销的屏幕提示，全屏时使用托盘通知 |
| 静默切换，不提示 | 记录切换，可从时间线、托盘或快捷键撤销 |

默认使用“自动（推荐）”，各设备在各场景从“自动切换，可撤销”起步。连续三次选择保持至少 30 秒后升一级，撤销或手动改选降一级。选择固定级别可直接控制执行方式。清除本机历史也会重置信任。

蓝牙播放优先选立体声端口，排除免提或已知单声道端口。如果同一耳机也承担默认录音角色，程序会优先沿用已有的独立话筒，其次选择唯一合适的话筒。缺少明确选择时保留现状。配对切换只迁移指向该耳机的输入角色，撤销同时恢复原来的输出和输入。如果 Windows 角色已经改变，会保留后来的选择。自行指定端口的应用仍按自身设置工作。

**切换与设置 → 活动时间线与撤销** 显示接入、断开、场景变化、自动动作、纠正、异常和最近七天的执行与纠正次数。选择记录可查看评分依据并离线回放。日志保留最近 30 天，最多 1,500 条、8 MiB，支持导入、导出和清除。导入记录仅供查阅与回放。程序在本机读取占用和类别，日志不含音视频、窗口标题或进程名。

首次运行 v1.1 会把旧版设备用途、端口偏好、自动切换和更新设置迁入 `%LocalAppData%\DeskAudioControl\settings.json`。决策记录保存在同目录的 `decisions.json`。Windows 登录启动项和当前用户加密的更新凭据仍由 Windows 管理。

## P3 声音调优

在 **声音调优** 选择具体的播放或录音端口。全新安装默认开启自动调音，从旧版升级的保持原来的开关状态，原先关闭的仍然关闭。

**等响切换与柔着陆**　在两个端口分别用同一参考音找到舒适音量，再点“记住当前音量”。最近 16 次校准会区分日间和夜间，并按时间和离群程度取舍。两侧同一时段各至少有 3 个有效样本时进行匹配。驱动增益曲线可用时，程序在 dB 域计算目标和淡入步进。样本不足时保留或降低原音量，耳机初次最多 35%，可为设备调低上限。音量、静音、默认角色或通话占用发生变化时停止淡入。

**麦克风医生**　点击“开始话筒检查”，先保持安静，出现提示后再说话。报告给出语音电平、峰值、削波、工频嗡声、低频振动、高频嘶声、带宽和回声风险。安静段混入语音时会提示重测。输入增益建议以 dB 显示，写入后可以复测或还原。分析在内存中完成。

**EQ 推荐与应用**　在设备页点击“耳机 EQ”，或从声音调优选择端口。名称匹配存在歧义时可查看候选并确认实物型号。强度滑杆控制各段增益，参数表、试听、导出和应用使用同一份规划。每份导出保留测量来源与许可。[测量与预设来源](https://github.com/jaakkopasanen/AutoEq/tree/7ae0f56d53074872b028649617a22bbb4232feb7/results/oratory1990)

已安装 Equalizer APO、在其配置器中注册端口且配置目录可写时，可点击“应用到此端口”。DeskAudio 保存原配置并引用单独的滤波文件。“还原 EQ”会保留其他端口的配置，最后一个端口还原后恢复原始字节。外部修改发生冲突时会显示原因。应用前后可在相同音量下测量参考音的环回频谱。实际效果取决于驱动处理顺序和应用播放模式。[Equalizer APO 配置说明](https://sourceforge.net/p/equalizerapo/wiki/Configuration%20reference/)

## 构建与运行

已在 Windows 10 x64 验证。构建使用 Windows 自带的 .NET Framework 4.x C# 编译器。在工程根目录打开 PowerShell 并运行

```powershell
.\Build.ps1
.\DeskAudio.exe
```

构建生成的 `DeskAudio.exe` 可独立运行。首次直接启动会打开设备面板；如需桌面入口，可为该文件创建快捷方式。在“切换与设置”中打开“登录 Windows 后启用托盘和快捷键”开关，即可启用登录启动。移动程序后，在新位置打开程序并把该开关关掉再打开，可更新登录启动路径。

设备列表会随连接状态刷新。智能切换沿用原有的接入自动切换开关设置。有独立设备设置的通话或播放应用，可在应用内选择“系统默认”来跟随切换。

## 离线测试

在工程根目录运行

```powershell
.\tests\Run.ps1
```

测试通过模拟设备数据检查新设备接入、同型号并存、USB 换口、蓝牙多配置、模拟插孔、场景迟滞、评分、自治反馈和路由恢复。测试可使用普通用户权限运行，编译产物写入当前用户的临时目录，并在完成后清理。
